## ✨ Key Features

- ⚡ **Multi-Threaded Turbo Engine**: Splits files dynamically into up to 32 concurrent HTTP segments to saturate your bandwidth.
- 🎥 **Auto Stream Sniffer & Extractor**: Built-in support for HLS (`.m3u8`), DASH (`.mpd`), YouTube, and 1,000+ streaming sites powered by embedded `yt-dlp` and `ffmpeg`.
- 🧩 **Zero-Lag Browser Integration**: Seamless 1-click download catching for Chrome, Edge, Brave, and Opera.
- 🔒 **Zero Telemetry & Private**: No analytics, no accounts required, no trackers, and absolutely no ads.
- 🔄 **Built-in Auto Updater**: Instant background delta updates with zero interruption.
- 📱 **Companion Android App**: Native Jetpack Compose Android client with background service & pause/resume reliability.
